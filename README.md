# AplicativodeControledeUsodeMedicamentos
 app que ajude o usuário a registrar e acompanhar o uso de seus medicamentos. Faça uso de SqLite para o CRUD. O usuário poderá cadastrar medicamentos como "Melhoral", "Paracetamol", "Omeprazol”, etc., acompanhado de horário que ele deve ser consumido. Quando o horário chegar, o usuário deve ser alertado do seu uso.
